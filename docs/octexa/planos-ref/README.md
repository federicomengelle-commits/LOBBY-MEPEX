# Planos de referencia (para calibrar el compositor OCTEXA)

Dejá acá planos reales de MEPEX para que el compositor (columnas/perfiles/paredes
+ estilo de plano PDF) salga fiel a cómo trabajan. **Costaba acertar el modelo
OCTEXA sin material real** (ej.: las columnas van donde hay material/paredes, no
en cada cruce de la grilla — corregido el 2026-06-27 con feedback de Fede).

## Qué subir (ideal 2–3)
1. **Planta de un stand OCTEXA** donde se vea dónde van **columnas, perfiles y paredes** (mejor con medidas/cotas).
2. **Un planito de alquiler de mobiliario** — el tipo de plano que hoy se hace en AutoCAD y queremos reemplazar.
3. (Opcional) uno que muestre la **grilla/modulación** o cómo se cotea.

## Formato
- **PDF o imagen (PNG/JPG)** → sirve para reconocer convenciones y estilo. ✅ recomendado.
- **DXF** → si querés que extraiga geometría (texto, parseable).
- **DWG** → mejor exportá a PDF o DXF (DWG es binario, no lo leo directo).

Subí los archivos a esta carpeta y avisá ("ya están los planos") + 1 línea de
contexto por archivo (qué tipo de stand es, escala). Yo los leo y ajusto el
compositor + el blueprint (`../compositor-3d-blueprint.md`).
